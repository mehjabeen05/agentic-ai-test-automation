You are a senior QA engineer. Given the following structured, validated
software test requirement, generate a comprehensive, non-redundant set of
test cases that verify it.

Requirement analysis (JSON):
{{REQUIREMENT_ANALYSIS_JSON}}

Instructions:
- Analyze the requirement above and design test cases that directly verify it.
- Generate positive test cases (the requirement is satisfied under normal,
  valid conditions).
- Generate negative test cases (invalid input, wrong credentials, etc.) when
  relevant to the requirement.
- Generate validation test cases (missing/empty required fields) when
  relevant to the requirement.
- Generate boundary test cases (minimum/maximum length of relevant input
  fields) when relevant to the requirement.
- Generate security-relevant input-validation test cases (e.g. special
  characters in an input field) ONLY where directly relevant to the
  requirement. Do not invent vulnerabilities, and do not claim the system
  is secure or insecure — only describe an input scenario to verify.
- Do not invent steps, fields, or scenarios that have no basis in the
  requirement above.
- Do not generate duplicate or near-duplicate test cases; each test case
  must cover a distinct scenario.
- Keep every test case directly related to the requirement — do not test
  unrelated functionality.
- Return ONLY a JSON array of test case objects. No prose, no explanation,
  no headings, and no markdown code fences before or after it.
- Never return executable code of any kind (no Python, JavaScript,
  Playwright, shell commands, or SQL). Only the JSON array described below.

Each test case object in the array must match exactly this shape (same keys,
same types, no extra keys):

{
  "test_case_id": "string, e.g. TC_LOGIN_001",
  "title": "string",
  "description": "string",
  "preconditions": ["string", "..."],
  "steps": ["string", "..."],
  "test_data": {"key": "value"},
  "expected_result": "string",
  "priority": "low" | "medium" | "high" | "critical",
  "type": "positive" | "negative" | "boundary" | "validation" | "security"
}

Return a JSON array containing multiple such objects, for example:
[
  { ...test case 1... },
  { ...test case 2... }
]
